# 固定配置与实现参数

本文集中记录复现所用的固定超参数、工程设置和历史标识映射。正文只按 **LAFAN1、未筛选 BONES、筛选后 BONES** 区分实验；这些配置不是实验名称，也不是本阶段主动改变的变量。科学问题、数据筛选与测评协议见 [PLAN_12_16_0.md](../PLAN_12_16_0.md)，训练观察见 [RESULT.md](../RESULT.md)。

第 1–3 节记录已完成实验的实际配置；第 4 节为下一阶段待实施的工程参数。`config.json` 与 `env_config.json` 保留执行参数（路径已规范化为仓库相对形式），本文是其阅读入口，不是训练器自动加载的配置文件。

## 1. 状态表示与网络

| 项目 | 固定设置 |
|---|---|
| 机器人 | Unitree G1，29 个受控关节 |
| 状态表示 | 根部与关节广义坐标；代码键 `representation=gencoord` |
| 原生任务 ID | `SuperMimic-GenCoord-G1`，仅在调用上游 CLI 时使用 |
| 世界模型 | MLP，隐藏层 2,048 / 2,048 / 2,048；预测速度增量后积分并恢复运动学状态 |
| 动作编码器 / 共享解码器 | MLP，隐藏层 2,048 / 1,024 / 512 / 256 |
| 潜变量 | 32 维，tanh 约束 |
| 策略输入 | 10 帧本体感觉历史及 10 帧未来参考动作 |
| Critic | MLP，隐藏层 256 / 128 |
| 当前训练接口 | 仅动作跟踪；速度接口权重为 0 |

论文中的网络结构见 [表 A.4](https://arxiv.org/pdf/2610.28480v2#page=15)。报告保留世界模型、策略与价值网络之间的理论关系，具体层宽和窗口长度以本文件为准。

## 2. 训练超参数与计算预算

| 项目 | 数值或设置 |
|---|---|
| 并行仿真环境 | 8,192 |
| 世界模型 batch | 每批 4,096 个状态窗口，每次更新 10 批 |
| 世界模型窗口 | 8 帧状态，当前实现监督 7 个状态转移 |
| 策略 batch / 更新批数 | 8,192 条想象轨迹 / 1 |
| 想象时域 | 32 步 |
| 学习率 | 世界模型、策略与 critic 均为固定 2×10⁻⁴ |
| 优化器 | 沿用当前发布代码的 Muon / fused Adam 实现 |
| 折扣 / GAE | γ=0.99，λ=0.95 |
| 策略 β₂ / 梯度逐元素裁剪 | 0.95 / 0.1 |
| 采集动作噪声标准差 | 0.1 |
| 可微软终止参数 | 0.05 |
| Replay buffer | 每环境 1,000 步 |
| Replay ratio | 16；当前配置约每个采集循环更新 0.4 次 |
| 动作起点采样 | return-based；γ=0.99，horizon=20，memory=256，steepness=25，explore=0.5，keep=0.1 |
| 采集预算 | 160,000 个循环，每模型 1,310,720,000 条仿真转移 |
| 实际学习更新 | 已完成模型各 63,997 次；新训练需核验实际计数 |
| 常规日志 / 快照 / 完整恢复保存间隔 | 50 / 5,000 / 10,000 个采集循环 |

世界模型 nominal error 参数：根部位置 0.01，根部姿态 0.02，关节位置 0.1，关节速度 3.14，身体位置 0.05，身体旋转 0.1，身体线速度 1.0，身体角速度 3.14。损失比较时同时核对预测长度、参与通道及其归一化，不能直接把当前标量与论文归一化误差等同。

重训只改变 BONES 的训练集合，保持上述配置及采样预算。策略、世界模型、critic、优化器、replay 和动作采样器从头初始化。短测产物不作为正式训练的初始权重。正常主实验完成固定预算，保存模型用于选优；数值异常时中断排查。

## 3. 仿真、运行与论文差异

| 项目 | 固定设置 |
|---|---|
| GPU | 每项任务单张 A100-80GB |
| 物理仿真 | MuJoCo Warp，物理步长 0.005 s，decimation=4 |
| 控制 / 参考频率 | 50 Hz，即 Δt=0.02 s |
| 训练 episode 时限 | 10 s，500 个控制步；完整动作测评取消此上限 |
| 奖励时间缩放 | 开启；跟踪正奖励权重和为 5，单步正奖励上界为 5Δt |
| GPU 执行优化 | 沿用已验证的世界模型和策略 CUDA Graph |
| 环境入口 | `bash reproduction/run_env.sh`；依赖恢复见 [复现指南](guides/reproduction.md) |
| 监控 | TensorBoard 记录训练与测评标量；tmux 显示任务、进度、有效吞吐和 ETA |

执行器参数、奖励各项、仿真求解器、训练随机化及观测完整定义保存在对应模型的 `env_config.json`，不在报告中重复展开。正式评测覆盖哪些设置由 PLAN 的测评协议决定，不能直接沿用交互回放默认值。

**与论文的配置差异。** 论文单卡设置使用 4,096 个环境、世界模型 batch 2,048、策略 batch 4,096，并采用 Adam 与余弦学习率衰减至初值的 0.03 倍；本次扩大了单卡并行规模，沿用发布实现的优化器与固定学习率。论文的 8 步预测定义与当前 8 帧状态窗口也需区别。这些差异保留为复现边界，本阶段不同时修改它们，以便单独观察训练数据筛选的影响。[论文表 A.5](https://arxiv.org/pdf/2610.28480v2#page=16)

## 4. 下一阶段的工程参数（待实施）

| 用途 | 计划设置 |
|---|---|
| 数据筛选进程 | CPU 16–32 个进程；先对 1,024 条动作计时，再按总帧数外推 |
| BONES 模型选优子集 | 固定 1,024 条筛选动作，按类别与时长分层；新旧模型共用同一清单 |
| LAFAN1 模型选优子集 | 固定 8 条代表动作 |
| 候选模型预算 | 每个条件最多 32 份已有快照；只选一个模型进入正式全集测评 |
| 选优顺序 | 完整动作等权归一化回报最高；差值 ≤10⁻⁴ 时依次比较失败数、身体位置误差、采集循环数 |
| 推理吞吐测试 | 在同一份至少 4,096 条的固定动作子集上测试 512 / 1,024 / 2,048 个环境；与选优子集分开 |
| 推理优化准则 | 正确性通过后按有效计分步/s 选择，留显存余量；空槽与 padding 不计入吞吐 |
| 模型切换 | 可复用同一进程，但重置全部物理状态、历史观测和上一动作 |
| 结果恢复 | 逐动作保存完成状态；重启只处理未完成或需重试的动作 |
| 图表处理 | 当前训练曲线按 100 个等宽采样量区间取均值；训练末段取最后 10% 预算 |

这些是工程设置，吞吐测试不构成新的科学对照实验。更改时记录生效版本；不得改变新旧 BONES 共用的测评协议。筛选门限和动作失效判据直接定义研究对象及指标，因此仍在 PLAN 中明确给出。

## 5. 实验入口、历史标识与模型文件

日常文档与生成结果统一使用下列实验入口。旧标识仅用于追溯不可改写的历史日志和兼容原运行路径。

| 当前入口 | 历史批次中的原目录 | 用途 |
|---|---|---|
| [`reproduction/experiments/lafan1/`](../reproduction/experiments/lafan1/) | `20261114_8xa100/lafan1_gencoord_x2/` | 已有 LAFAN1 模型 |
| [`reproduction/experiments/bones_unfiltered/`](../reproduction/experiments/bones_unfiltered/) | `20261114_8xa100/boneseed_gencoord_x2/` | 已有未筛选 BONES 模型 |
| `reproduction/experiments/bones_filtered/` | 尚未建立 | 筛选后从头训练的新模型 |

前两个入口是仓库内相对符号链接，不复制权重。历史配置中的路径已规范化为仓库相对路径，数值超参数与训练日志不变。Git 只分发配置与小型统计，模型、原始数据、日志及视频需随服务器迁移单独复制。完整归档仍位于 `reproduction/campaigns/`，其中其他模型不参与当前报告和下一阶段主对照。

每组已完成训练的最终快照为 `checkpoints/00160000/`。快照包括 `actor.pt`、`world_model.pt`、`critic.pt`；`resume.pt` 另存优化器、replay 和采样状态。正式测评加载同一快照的 actor、世界模型 bundle 及原配置，仅使用策略与物理仿真；不执行想象 rollout 或梯度更新。实际选中的最佳模型由后续 `selected_models.json` 记录，不默认把最终快照当作最佳模型。

原始配置入口：[LAFAN1 训练配置](../reproduction/experiments/lafan1/config.json)、[LAFAN1 仿真配置](../reproduction/experiments/lafan1/env_config.json)、[BONES 训练配置](../reproduction/experiments/bones_unfiltered/config.json)、[BONES 仿真配置](../reproduction/experiments/bones_unfiltered/env_config.json)。

重新生成当前报告与图表：

```bash
bash reproduction/run_env.sh python scripts/reporting/write_training_result.py --refresh-report
```

只更新报告正文和派生统计时使用 `--report-only`。这两个入口不启动训练，也不修改模型权重。

路径以仓库根目录为基准；外部数据通过 `SUPERMIMIC_DATA_DIR` 映射，环境与依赖由 `SUPERMIMIC_ENV_PREFIX`、`SUPERMIMIC_MJLAB_DIR` 指定。迁移步骤及本机覆盖文件见[复现指南](guides/reproduction.md)。旧恢复文件内嵌路径由加载器兼容，无需改写模型张量。
