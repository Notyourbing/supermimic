# 接下来做什么

正式训练尚未启动。以下按顺序推进，已有证据和未完成事项分开记录。

1. 在新服务器运行 bootstrap、数据校验、官方测试及两种表示的 smoke test，保存新运行名与新硬件信息。确认 GPU 资源归属；原服务器其他用户的 8 卡任务没有被停止。
2. 在空闲 A100 上用默认规模短测：4096 环境、WM 2048×10、policy 4096、窗口 8、想象长度 32、proprio/历史 10、固定种子 42。区分编译启动开销和稳定吞吐，测本进程利用率，保留显存余量。
3. 明确正式复现目标：当前官方代码基线，或严格论文协议。LAFAN1 可以直接使用；论文完整 BONES 对照需要补齐 129,514 条精确筛选清单，不能直接使用 `packed_unfiltered` 宣称论文覆盖率。
4. 若对齐论文，再落实 Adam、余弦学习率与迭代计数含义；当前上游使用 Muon/fused Adam、固定学习率。将这些变化作为独立配置并验证，保留当前官方实现基线。
5. 默认 batch 先建立效果基线。WM 4096 / policy 8192 已通过速度短测，但每收集循环的优化器更新数减半，需要等协议/效果比较后采用。
6. 明确预算后再启动正式训练，记录数据摘要、两仓库提交、配置、收集循环数、学习更新数和硬件。32 万是显式预算，原代码默认 100 万；短测检查点没有收敛，不能作为正式模型。
7. 实现正式全库评测：固定评测种子、训练终止条件、从动作首帧运行、统计回报及失败动作；按长度分桶并在 GPU 间分片，减少尾部等待。45–90 分钟/检查点/8 卡目前只是共享负载下的规划估计。
8. 收敛后生成 reference motion 与实际策略动作同步对照的视频，并记录模型与数据摘要。更新报告和正式结果。

如果只有一个模型需要 8 卡同步训练，需额外实现并验证梯度、normalizer、采样分布同步及 CUDA Graph/NCCL 交互。当前没有这项能力，不能把 8 个独立进程当成 DDP。

本提交没有修改上游训练算法；它交付环境、数据流水线、验证、机器实测证据与迁移入口。旧 Dex-Supermimic/Hand2 项目与本次官方 G1 项目分开保留，未并入这个 fork。
